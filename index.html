🔥 Firebase'de Nereye Bakacaksın

  1. Firebase Console → Analytics → Acquisition → User acquisition
    Burada First open by campaign tablosu var. Etiketli link kullandıysan kampanya adın burada belirir.
  2. Analytics → Events → first_open → kampanyaya göre filtrele
    Boyutlar: source, medium, campaign
  3. Analytics → Retention → kampanya segmenti oluştur
    Kritik soru: reklamdan gelen kullanıcı organikten daha mı iyi tutunuyor? Kötü tutunuyorsa kanal yanlış kitleye ulaşıyor demektir.
  4. Audiences → New audience → campaign = <kampanya adın>
    Bu segmenti oluştur, sonra retention ve gelir raporlarında ayrı izle.
